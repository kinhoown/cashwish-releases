# CashWish — baixar o app

App de finanças pessoais, pro celular (Android) e pro computador (Windows).
Os links abaixo sempre baixam a **versão mais nova**.

[![Versão mais nova](https://img.shields.io/github/v/release/kinhoown/cashwish-releases?label=vers%C3%A3o%20mais%20nova)](https://github.com/kinhoown/cashwish-releases/releases/latest)

## 📱 Celular (Android)

### [⬇️ Baixar CashWish-Android.apk](https://github.com/kinhoown/cashwish-releases/releases/latest/download/CashWish-Android.apk)

Ou aponte a câmera do celular pro código:

<img src="imagens/qr-android.png" alt="QR code pra baixar o CashWish no Android" width="180">

1. Abra o arquivo baixado e toque em **Instalar**.
2. Se o Android pedir, permita instalar apps dessa fonte (navegador ou
   Arquivos).

## 💻 Computador (Windows)

1. **Só na primeira vez:** [⬇️ baixe o certificado](https://github.com/kinhoown/cashwish-releases/releases/latest/download/CashWish-certificado.cer)
   e instale seguindo o [guia de instalação](https://github.com/kinhoown/cashwish-releases/releases/latest/download/COMO_INSTALAR_WINDOWS.txt)
   (Computador local → Autoridades de Certificação Raiz Confiáveis).
2. ### [⬇️ Baixar CashWish-Windows.msix](https://github.com/kinhoown/cashwish-releases/releases/latest/download/CashWish-Windows.msix)
   Dê um duplo clique no arquivo e toque em **Instalar**.

## Já tem o app instalado?

Não precisa baixar de novo: o CashWish avisa sozinho quando sai versão nova.
Pra conferir na hora: **Perfil > Verificar atualizações**.
